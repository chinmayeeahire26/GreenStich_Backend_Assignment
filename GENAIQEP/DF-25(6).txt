Common causes and fixes:

- You’re expecting the API to echo your prompt back. Many APIs don’t return the original prompt by default. Fix: store the prompt client-side; don’t expect it in the response.
- Wrong response field. For OpenAI-style responses, you typically want:
  - Chat Completions: `response.choices[0].message.content`
  - Responses API: `response.output[0].content[0].text` (structure can vary)
- You’re using `stream=true`. Streaming responses arrive in chunks; the full structure isn’t present until you assemble it. Fix: accumulate deltas/events and then parse.
- Your SDK version changed the schema. Fix: check the SDK docs/changelog and update your parsing accordingly.
- Middleware/logging layer stripping fields. Some proxies remove request/diagnostic fields. Fix: inspect the raw HTTP response.
